# 英语单词页面

这是英语学习网页（Compass 1000 Basic，Unit 1 Part A）。

## 文件说明

- `index.html`：网页本身。用浏览器打开就是单词页面（10 个单词、发音、跟读评分）。
- `assets/vosk.js`：语音识别程序。跟读评分用的，不用单独打开。

## 怎么打开

用这个网址打开（大陆网络和 QQ 浏览器都能打开）：

https://cdn.jsdelivr.net/gh/Wilson600812/english-words@main/index.html

## 说明

- 语音识别用的模型不在这个仓库里，第一次点“跟读”时会从网上下载，之后存在浏览器里，离线也能用。
- `index.html` 和 `assets/vosk.js` 这两个名字不能改，网页是靠这两个名字找到文件的，改了页面就打不开了。
