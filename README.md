# 英语单词页面

https://wilson600812.github.io/english-words/

手机、电脑、墨水屏，任何设备打开都是同一份内容。

## 结构

- `index.html`：**一级目录**，列出所有合集
- `第一册/`：1000 Basic English Words 第一册，240 词，24 课
  - `第一册/index.html` 第 1 课，`第一册/第NN课.html` 其余各课
- `句子朗读/`：小学句子朗读，100 句，10 页（目前做了第 1 页）

## 第一册（单词页）

- 每个词三行：单词 + 音标 + 中文意思／词性 + 英文释义 + 中文／例句 + 中文翻译
- 点每行最左边的小喇叭听发音
- 「跟读」录音：读完停 2 秒自动结束；录完点「播放我的录音」回放对照
- 顶部「连读」：从第 1 条读到第 10 条，只读单词和例句，跳过释义行
- 顶部方格：一册 24 课，左右箭头翻一屏，点方格跳课
- 方格颜色：白=没学，绿=已学，黄=已掌握，橙=已复习；底部三个按钮打标记，再点一次取消

## 句子朗读

- 每句一行英文 + 一行中文，点喇叭听**原声**（从整段音频里切出来的，不是 TTS）
- 同样有「跟读」「连读」和方格进度

## 注意

- 不评分、不识别、不下载任何模型，打开就能用
- 学习状态存在浏览器本地（localStorage），**每台设备各记各的，不跨设备同步**；清缓存会清零
- 页面里的音频是 base64 内嵌的，断网也能听
