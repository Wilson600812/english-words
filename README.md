# 英语单词页面

这是英语学习网页（Compass 1000 Basic，Unit 1 Part A）。

## 文件说明

- `index.html`：网页本身。用浏览器打开就是单词页面（10 个单词、发音、跟读录音）。

## 怎么打开

用这个网址打开（大陆网络和 QQ 浏览器都能打开）：

https://wilson600812.github.io/english-words/

## 用法

- 点小喇叭听原音（单词、释义、例句都有发音）。
- 点“跟读”自己录音：读完停 2 秒自动结束，录完点“播放我的录音”回放，和原音来回对照，自己听着纠正。
- 不评分、不识别、不下载任何文件。
