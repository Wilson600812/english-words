# 英语单词页面

Compass **1000 Basic English Words** 第一册。每页 10 个单词，带发音、跟读录音和课时进度标记。

## 打开

https://wilson600812.github.io/english-words/

手机、电脑、墨水屏，任何设备打开都是同一份内容。

## 文件

- `index.html`：第 1 课（Unit 1 Part A，1–10）
- `第一册-第02课.html`：第 2 课（Unit 1 Part B，11–20）
- 以后每课一个文件，命名 `第一册-第NN课.html`，都放在根目录

## 怎么用

- 点每行最左边的小喇叭听发音（单词、释义、例句都有）
- 点「跟读」录音：读完停 2 秒自动结束，也可以点「■ 停止」；录完点「播放我的录音」回放，和原音对照
- 顶部方格子是这一册的 24 课：左右箭头翻一屏，点方格直接跳课
- 方格颜色：白=没学，绿=已学，黄=已掌握，橙=已复习。每页底部三个按钮打标记，再点一次取消
- 不评分、不识别、不下载任何模型，打开就能用

## 注意

- 学习状态存在浏览器本地（localStorage），**每台设备各记各的，不跨设备同步**；清浏览器缓存会清零。
- 页面里的音频是 base64 内嵌的，所以断网也能听。
